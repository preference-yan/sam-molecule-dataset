# SAM–钙钛矿复合结构数据集

本仓库保存作者自行构建的 **5,116 个 SAM–钙钛矿基底复合结构**。每个 `.extxyz` 文件同时包含分子与基底，保留原始坐标、晶胞、周期性边界、原子标签及能量字段，逐字节复制并通过 SHA-256 核验。

这是 5,116 个界面结构，对应现有清单中的 **89 种分子身份**，不是 5,116 种独立分子。仓库不包含 QM9、通用预训练库、新生成分子或模型权重。

## 数据规模与既有划分

| 分区 | 复合结构数 | 分子身份数 |
| --- | ---: | ---: |
| train | 4,039 | 71 |
| val | 557 | 9 |
| test | 520 | 9 |
| 总计 | 5,116 | 89 |

沿用既有 seed 2025 的分子身份划分，分组字段为清单中的 `canonical_smiles`；三个分区之间该字段的交集为零。此核验不等同于骨架不重合，也不证明历史模型从未接触测试数据。原始 `smiles` 和既有 `canonical_smiles` 均保留，不重新规范化或改变立体化学标注。

| 原始表面族标签 | 结构数 |
| --- | ---: |
| CsPbI3 | 264 |
| FA0.95CsPBI3 | 2,332 |
| H5PbCI3N2 | 1,580 |

以上标签按原清单原样保留。全部结构合计 32,516,940 字节，单个结构含 26–189 个原子。

## 文件与字段

- `data/{train,val,test}/*.extxyz`：全部原始结构文件。
- `metadata/catalog.csv`：逐结构索引、分子标识、表面标识、原子数与原始能量值。
- `metadata/manifest.json`：既有划分及逐结构 SHA-256，另附仓库相对路径。
- `metadata/summary.json`：全量解析核验及计数汇总。
- `metadata/source_integrity.json`：导出前后源文件一致性记录。
- `metadata/transfer_manifest.json`：结构及上述元数据的传输校验值。

`.extxyz` 的位置和晶胞按 ASE 的 Å 单位约定读取。当前数据中 `tags == 0` 为基底，`tags == 2` 为 SAM。原文件还保留 `spacegroup_kinds`、`pbc`、`facet`、`smiles`、`n_slab_atoms` 和 `n_sam_atoms`。

`adsorption_energy`、`e_slab`、`e_mol` 是原项目计算标签。本次导出没有重算能量、转换单位、变更能量参考或追加物理验证；计算方法、单位与能量参考需以原始计算流程为准。**57 条正吸附能记录全部保留**，不得因正值而静默替换样本。结构解析成功及坐标有限不代表吸附稳定或化学几何已获物理验证。

## 使用

先在克隆的仓库中执行完整性检查（只需 Python 标准库）：

```bash
python3 scripts/verify_dataset.py
```

如需读取结构，安装 ASE 后运行示例：

```bash
python3 -m pip install -r requirements.txt
python3 examples/read_structure.py
```

示例通过文件句柄读取，避免原文件名中的特殊字符被解析成 ASE 的帧选择语法。使用清单的 `path` 查找结构，不要仅依赖文件名中的截断分子名称或四舍五入的能量值。
