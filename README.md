# SAM–钙钛矿复合结构数据集

版本 **v1.0.0**。包含作者自行构建的 **5,116 个 SAM–钙钛矿基底复合结构**。

| 目录 | 结构数 |
| --- | ---: |
| `data/train/` | 4,039 |
| `data/val/` | 557 |
| `data/test/` | 520 |

每个 `.extxyz` 文件同时包含 SAM 分子和钙钛矿基底，保留原始坐标、晶胞、周期性边界及计算标签。原子 `tags=0` 表示基底，`tags=2` 表示 SAM；`adsorption_energy`、`e_slab`、`e_mol` 为原始能量值，单位与计算方法以原始计算流程为准。

结构可用 ASE 读取。所有结构文件与首次上传版本逐字节一致；目录沿用既有分子身份划分。此版本仅保留原始数据和本说明。

本仓库公开提供本数据集；未经作者许可，请勿再分发。
